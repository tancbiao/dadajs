## 一、作品名称

人生模拟器 · 十八岁那年你觉醒了系统

## 二、一句话介绍

一个纯前端的人生模拟器：你先被家庭养大，18 岁那年觉醒一个随机系统，然后带着它去活完一生——天赋、父母、学校、皮质醇，全都会改你的脑子。

## 三、作品简介（200 字内，可直接填表）

出生不由你选，父母不由你选。前十八年，你会被报班、被比较、被塞一部手机喂饭、被分进"卷王班"。你选的天赋可能是祝福，也可能是诅咒——只有高知或放养的父母养得住它，其余家庭大概率把它毁掉。

18 岁那年，系统来了。它可能是神豪返利，也可能是死亡回归；你可能穿越到大海贼时代、修真界，也可能被留在原地。

之后是一生的账：收入、负债、皮质醇、人格、名声，以及你最后留下什么。

全部逻辑跑在浏览器里，可离线，可接 DeepSeek 做"世界导演"，不接也能玩完整局。

## 五、玩法（三步）

1. **选天赋 → 被养大**：每个选项都在改你的脑子和性格。
2. **18 岁觉醒**：抽一个系统，决定你穿越到哪个世界。
3. **活完这一生**：每年一个决策，中间可以"直接去做"（比如去干四皇）、可以快进、最后结算人格、成就与评分。

## 六、技术说明

- 纯静态：HTML + CSS + 原生 JS，零依赖、零构建，双击 `index.html` 即可玩
- 数据驱动：系统 31 个 / 世界 19 个 / 事件 100+ / 套路 50 条，全部是 JSON 式配置，加内容不用改引擎
- 可选 AI：`/api/chat` 走 DeepSeek，前端不存 Key；离线自动降级到本地事件库
- 本地存档：`localStorage`，每年自动存，退出可续
- 移动优先：竖屏、吸底按钮、结果底部弹层
