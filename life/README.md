# 人生模拟器 · 系统觉醒

一个**文字人生模拟**网页游戏：你出生在 20XX 年的中国，前十年的活法由父母和学校决定；18 岁那年，一份"神经发育报告"摊开在你面前，同时觉醒一个随机"系统"；之后带着面板和一张经济账单，过完这一生。

- 手机竖屏优先，纯静态，双击即玩
- 15+2 个世界 · 31 个系统 · 36 个成年事件 + 7 个生活事件 + 5 个经济事件
- 可接 DeepSeek / 任意 OpenAI 兼容接口；玩过的剧情会入库复用，省 token
- 自带系统编辑器；玩过的人生可被别人"从同一个起点重活"

## 二、这一版的核心：出生面板

开局**不选世界**，也不选父母。你只填名字和性别，剩下的交给概率。

### 1. 父母（6 类，知识分子只有 12%）

| 类型 | 概率 | 特征 |
|---|---|---|
| 市井务实型 | 28% | 爱你，但没主意，听专家、听亲戚、听邻居 |
| 焦虑虎妈型 | 22% | 补习班排满，考 98 分要问那 2 分扣在哪 |
| 放养型 | 16% | 饭在锅里，钥匙在门口 |
| 缺席型 | 14% | 留守 / 离异 / 在外打工 |
| 知识分子型 | 12% | 会停下来回答你的"为什么" |
| 严控型 | 8% | 打骂、罚站、翻日记 |

### 2. 学校（家长安排，你不能选）

公办普通 / 公办重点（课间不许出去，25%）/ 普通私立（三年级还在背乘法口诀）/ 贵的私立。

> 普通私立转回公办，数学从 90 分掉到 10 分——这是**教学进度与评价体系错位**，会做成一个真实事件。

### 3. 七项隐藏指标（1–17 岁每年结算）

| 指标 | 怎么涨 | 怎么掉 |
|---|---|---|
| 神经元发育 NDI | 运动、自由玩耍、同龄社交、睡眠充足 | 皮质醇高、课业挤压、被打断 |
| 皮质醇 | 学业压力、家长施压、羞辱 | 运动、玩耍、睡够 |
| 专注力 | 玩玩具/看书时**没被打断** | 频繁打断、高压 |
| 镜像神经元 | 和同龄人混在一起 | 长期独处、只刷题 |
| 体能 | 体育课、跑跳 | 久坐、熬夜 |
| 抗压能力 | 高发育 + 低皮质醇 | 长期高压 |
| 智商（隐藏） | 18 岁才结算 | — |

**18 岁结算公式**（简化）：
```
IQ ≈ 出生IQ + 0.30×(NDI−70) + 0.09×(专注−42) + 0.04×(镜像−42)
        − 0.09×max(0,皮质醇−45) − 0.05×睡眠债 + 父母引导
```
基线 **IQ 106 / SD 12**（金坛儿童队列 n=798 全量表均值 103.8、SD 11.9；Lynn 数据集 105）。
实测分布：p10 ≈ 93，中位 ≈ 107，p90 ≈ 126，最高 ≈ 138–145。
**131 以上约 3%**——只有这些人能"再烂的系统也玩出花样"。

### 4. 选择权是长出来的

| 年龄 / 智商 | 你能看见几个选项 |
|---|---|
| 1–9 岁 | **0 个**。全是家长安排，你只负责被养 |
| 10 岁起，IQ < 120 | **2 个**，而且经常不是最好的两个 |
| IQ ≥ 120 | **3 个** |
| IQ ≥ 131 | 3 个 + 一条【系统】骚操作 |

选项**不会告诉你加什么属性**。看不看得见第三条路，取决于你被养成了什么脑子。

**童年不是只有播报**：8 / 11 / 12 / 16 岁各插一场"学校生活"——

| 年龄 | 场景 | 有没有选择权 |
|---|---|---|
| 8 岁 | 专家进校园：跟着做操，还是坐着听"爱与奉献" | 没有。学校替你选， cortisol 直接结算 |
| 11 岁 | 书报亭那本漫画（选了才能解锁火影/海贼穿越） | 有 |
| 12 岁 | 课间十分钟：溜出去打球 / 趴着补觉 | 有 |
| 16 岁 | 天台上的烟 | 有 |

> 文案按年龄分桶（1 / 2–3 / 4–5 / 6 / 7–9 / 10–12 / 13–15 / 16–17），相邻两年不会播同一句；
> 私立小学会触发"转公办后数学从 90 掉到 10"，并且学校会真的换掉。

### 5. 行动力与"你看得到几个办法"

**行动力随年龄衰减**：18–44 岁 3 点，45–59 岁 2 点，**60 岁以后只剩 1 点**。老年不是不自由，是没力气。

#### 节奏（参考《人生重开模拟器》）

之前的毛病是"每年都在赶场"。现在按年龄自动减量：

| 阶段 | 一年几张卡 |
|---|---|
| 1–5 岁 | **1 张速写卡**（五个年龄写在一张里，发育照算，但不用点五次） |
| 6–9 岁 | 1–2 张（叙事 + 可能的学校生活） |
| 10–17 岁 | 每年最多 1 个选择 + 0–1 个生活事件 |
| 18–29 岁 | 最多 3 件（主事件 + 生活 + 经济） |
| 30–59 岁 | 最多 2 件 |
| 60 岁以后 | **只留 1 件主事件** |
| 65 岁以后 | 还有 28% 的年份是**「平静的一年」**，什么都不会发生 |

实测 20 局：18–29 岁平均 1.31 件/年，30–44 岁 1.02，45–59 岁 1.01，60+ 正好 1.00。
**老了以后，日子是自己慢下来的。**

**行动按钮不是永远 6 个**，智商决定你"知道几种活法"：

| 智商 | 可见行动 |
|---|---|
| <95 | 3 个：苦练 / 搞钱 / 静修 |
| 95–104 | 4 个（加"结交"） |
| 105–111 | 5 个（加"钻研"） |
| ≥112 | 6 个（加"冒险"） |
| 自研行动 | 需要 IQ ≥ 100 才想得起来用 |

### 6. 系统掌握度

18 岁还会算一个 `掌握度 = f(NDI, IQ, 抗压, 专注, 皮质醇)`：

| 掌握度 | 档位 | 后果 |
|---|---|---|
| < 18 | 完全不会用 | 只能"随便按一个"，效果减半 |
| 18–38 | 勉强摸索 | 效果 0.8，看不到成功率 |
| 38–62 | 用得挺顺 | 正常，显示成功率 |
| ≥ 62 | 钻研透了 | 效果 1.3，暴击更多，额外骚操作 |

中位数大约 **22–30**——也就是说，**大部分人拿到系统也不会用**。这就是"绞尽脑汁也只能想出以下几种使用方法"。

### 7. 教育政策与家长投诉（这一版的重点）

学校不是背景板。**政策会生效，也会被打断**，效果每年结算：

| 政策 / 师资 | 触发 | 每年效果 | 中断风险 |
|---|---|---|---|
| 专家进校园：课间动起来 | 6 岁（一年级），95% | 智力 +0.1、神经元 +1.2，持续到 12 岁 | 公立每年 38%、私立 17% 被家长投诉（摔伤 / 追责） |
| 班主任培训（杜威·陶行知） | 8–10 岁，30% | 智力 +0.1，到 12 岁 | — |
| 数学老师培训（做中学） | 8–11 岁，28% | 智力 +0.2，到 12 岁 | — |
| 科学探究课 | 9–12 岁，45% | 智力 +0.5、神经元 +2，到 12 岁 | 每年 55% 因"安全谁负责"被投诉停课 |
| 初中早七晚十 | 13 岁，90% | 智力 -0.3、神经元 -2.5、睡眠 -1.5 | 持续到 15 岁 |

关键机制：**课间被投诉取消后，会再挂一条持续减益**（每年神经元 -0.8）。
所以你会在 18 岁报告里看到这种落差：

```
课间运动   · 1 年   智力 +0.1 / 神经元 +1.2   投诉中断 @7岁
课间被取消 · 5 年   神经元 -4                  已结束
科学探究课 · 1 年   智力 +0.5 / 神经元 +2      投诉中断 @11岁
教育累计：智力 +1.1
你享受过课间运动、科学探究课，但都被家长投诉打断了。
学校永远选最安全的做法，代价由孩子承担。
```

**实测 200 局**：课间运动平均只活了 2.5 年（设定上本可以 6 年）；
92% 的人拿到正教育收益，但平均只有 +0.8 智商——这就是"本来可以更好"的部分。

> 这一层的目的不是让你赢，是让你看懂：**孩子的脑子，是被一整套制度养出来或削掉的。**

### 8. 手机、短视频与科学解释（新增）

小学阶段不再是"只有家长安排"。这些事件是**随机**的，不是每一世都会遇到：

| 年龄 | 事件 | 关键 |
|---|---|---|
| 7–9 | **被窝里的那块屏幕** | 偷玩手机到没电 → 睡眠 × 专注 × 神经元一起掉 |
| 9–12 | **一刷就到两点** | **IQ < 100 时只剩一个选项**——你根本想不到"放下手机"这条路 |
| 10–13 | **饭桌上的三块屏幕** | 父母各刷各的。选「一起刷」或「不要成为这样的人」 |
| 12–14 | **六年级的"团队"** | 拍猎奇 / 打擦边球 / 搞饭圈 / 不参与。每条都有代价 |

凡是能用科学解释的，卡片下面都有一个 **🔬 科学解释**（点开才看）：

> **为什么停不下来**：短视频是可变间隔强化（和老虎机同一套机制）——你不知道下一条好不好看，所以停不下来。青少年前额叶尚未发育成熟，抑制"再看一条"的能力比成人弱。

不是"教育你"，是把机制摊开给你自己判断。

### 9. 自创用法：玩家打字，AI 裁决

18 岁后，每年可以在行动页写一句「我想这样用系统」。

判定是两段式的：

1. **AI 判规则**：这个用法在机制内是否成立（feasible + 0–100 分），并给出一句具体的理由。
2. **你自己的条件再打折**：`成功率 = 机制分×0.55 + 智力系数×0.25 + 掌握度×0.2`

所以同一个点子，不同的人做，结果不一样：

| 条件 | 实测成功率 |
|---|---|
| IQ 95 | 53% |
| IQ 105 | 58% |
| IQ 125 | 66% |

更狠的一层：**IQ < 115 时，即使这个用法成立，你也可能"想不下去"**。
文案会把你的来路摊开——

> 你把这个想法在脑子里过了一遍，然后就卡住了。
> 不是它不成立——是你说不出下一步该干什么。
> 你从小到大的路：放养型的家庭、公办重点小学、只有 32 的神经元发育、长期偏高的皮质醇。
> 这条路没教过你这种思路。
> （这个用法其实是成立的。只是你的脑子，到不了那儿。）

实测 IQ 85 的角色，12 次研究里有 11 次卡在这一步。

- 成功 → 一次性收益 + 掌握度 +3，并写进**系统库**；别人打开这个系统，会看到「玩家研究出的用法」
- **更关键的是：研究会给你一个新动作，直接顶替六个基础行动里的一个。**
  比如研究出「找架打」，它就替换掉「冒险」，长期强度从 2 提到 3–8（研究分越高越强）。
  从此你的行动栏是「苦练 / 钻研 / 结交 / 找架打（自研）/ 搞钱 / 静修」——这一格是你自己想出来的。
- 失败 → 掌握度 +1，但会告诉你为什么不行
- 没配 API 时用本地规则审核（关键词 / 代价 / 夸张词），标「离线审核」

## 三、成年：多事件 + 经济

每年不再是"一件事"，而是 **2–3 件**：

1. **主事件**：AI 现写 / 别人人生缓存 / 离线模板
2. **生活事件**：专家进校园、课间十分钟、天台上的烟、书报亭的漫画……
3. **经济事件**：买房、创业、投资、婚礼预算、传销

### 经济面板（18 岁解锁，但**年薪是 0**）

18 岁那天你什么都没有。工资不看你"觉醒得多早"，看你的**学历路线**：

| 智商 | 路线 | 毕业年龄 | 毕业年薪 |
|---|---|---|---|
| ≥131 | 读研 | 25 岁 | 34 万 |
| 118–130 | 本科 | 22 岁 | 20 万 |
| 108–117 | 大专 | 21 岁 | 11 万 |
| 98–107 | 高中毕业 | 19 岁 | 6.5 万 |
| <98 | 打零工 | 19 岁 | 3.2 万 |

读书期间主动收入**一直是 0**，还要还助学贷款（25 岁读研毕业时账上通常是负的）。毕业那一年才开始拿工资，日志会写清楚。

**搞钱这件事，智商决定结局**：
- IQ ≥ 98：正常判定，可能赚到
- **IQ < 98：没有选项，必定被骗**（"稳赚不赔的门路"→ 转钱 → 对方失联），现金扣光、上负债、皮质醇飙升

低智商专属的无选项剧情还有：老同学的"阳光工程"、借钱办三十桌婚礼、下班跑单到没有周末。

| 项 | 说明 |
|---|---|
| 主动收入 | 由 IQ 决定档位：4.2 / 7.2 / 11.5 / 19 / 34 万/年 |
| 被动收入 | 房产、指数定投等资产产生 |
| 年支出 | 随结婚、生子、房贷上升 |
| 负债 | 6% 年息，有余钱会自动还；超过年收入 4 倍触发**债务重组** |

**IQ 决定你有没有决定权**：
- IQ < 112：结婚、被"阳光工程"拉走、跑滴滴——**没有选项，直接播报结果**
- IQ ≥ 112：同样的场景会给你 2–3 个选项；传销局里你能识破，甚至反手把结构摸清举报
- 被骗也会留下"经验"（tag），高智商能在下一局把它变成筹码

### 穿越

**觉醒即穿越**——不会再让你留在现代都市。系统有自己的"出身"（`SYS_HOME`），例如修仙系统 → 修真界、序列扮演 → 诡秘、卡牌 → 忍者世界；没有出身就随机落到一个世界。

落地的一瞬间，**身体被这个世界的规则重写一遍：全属性 +15%～35%**（穿越熟练越高越多）。这就是"大杀四方"的本钱——不是慢慢熬，是开局就比本地人强一截。
10 岁左右**选择看漫画**，会把火影 / 海贼两个世界加进穿越池。

穿越后的身份也按 IQ 分档：
- 低：还债的猎魔人、码头扛货的异乡人、被雇佣的炮灰
- 中：小有名气的冒险者、公会固定成员
- 高：公会里最年轻的分析师、能改写规则的那一类人

**初中（14 岁）会有人塞给你一本小说。** 熬夜看完、看完再翻一遍，会攒下「穿越熟练」：
- 熟练 30+：至少你认得那些规矩，身份不会落到最底层
- 熟练 60+：落地就知道哪条街不能走，身份直接提一档
- 熟练还会把**穿越后头几年的年死亡率压到 40%**（普通人的头几年最容易被这个世界弄死）

熟练只看小说（和漫画）看得有多深，跟智商无关——这是"读过"和"没读过"的差别。

### 寿命与死亡

- **每年都有死亡率**：现代都市约 0.4%/年，越老越高（45 岁后每年 +0.14%），越危险的世界越高（修真界约 0.8%）。
  体、运两维会往下压一点。死亡按世界抽具体死因（车祸 / 体检报告 / 妖兽 / 天劫 / 义体过热 / 冷箭…）。
- **濒死两次**：普通人不是一碰就死。前两次气血归零会被拉回来（"这一生只有两次这样的运气"），第三次才真的结束。
- **寿命**：基础 62 + 体×0.9。
  - 修真界：**+30 + 灵×2.2 + 境界×4**（20 级实测 197 岁）
  - 魔法/神秘侧（异世界、艾泽拉斯、深海）：+12 + 灵×0.8
  - 赛博/星际：+8（义体）
- **结局尾话**：按"最高维度 + 净资产 + 世界 + 智商 + 是否死过"组合出一段收尾，例如
  > 你活了 197 年。同辈的坟头草换了几十茬，你还在。
  > 你到最后都在看远处，没人知道你看见了什么。

## 四、接 AI

「设置」里的参数已按 2026 年官方文档校正：

| 字段 | 正确值 | 说明 |
|---|---|---|
| 接口地址 | `https://api.deepseek.com` | **不带 `/v1`**（旧写法会 404） |
| 模型 | `deepseek-flash` | = DeepSeek-V4.1-Flash-1017；也可填 `deepseek-v4-pro` |
| 思考模式 | **关闭** | 官方默认开启且 effort=high，游戏会被拖慢数倍、还多烧 token |
| JSON 输出 | 开启 | `response_format: {type:'json_object'}`，prompt 里已带 json 样例 |
| 单局上限 | 60 | 一局最多调多少次，防跑飞 |

> 官方文档：<https://api-docs.deepseek.com/zh-cn/>

### Key 存在哪

- 本机 Key 写在该文件：**`js/config.local.js`**（已在 `.gitignore` 里，不会进 git）
- 设置页只显示打码（`sk-13e••••6f01`），留空保存不会覆盖内置 Key
- **把游戏发给别人之前，请删掉 `js/config.local.js`**，否则等于把你的额度送人

### 为什么必须用 `启动游戏.bat`

浏览器直连 `api.deepseek.com` 会被 CORS 拦。用 bat 打开时，游戏会自动走同源 `/api/chat`（`server.js` 里的转发），不需要手填中转地址。直接双击 `index.html` 也能玩，但 AI 会失败并自动回落离线剧情。

**省钱机制**：AI 写的事件按 `世界|系统|年龄` 存成片段，下一个人走到同一年龄直接读现成的。
`replay`（重活别人的人生）会强制走缓存，保证剧情一致。
