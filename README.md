# 米菲 · 个人效率工作台（dada 工作台）

单文件零依赖的个人效率工作台，面向小学教师日常使用。

## 在线访问
- 正式域名：`dadajs.cn`（绑定中）
- GitHub Pages：`https://tancbiao.github.io/dadajs/`

## 功能
- ⏱ 倒计时（监考 / 学习双模式，结束提醒，全屏专注）
- 🖼 封面全局生效（换一次封面，所有页面一起换）
- 🎬 B站视频直达 + 快捷入口自定义
- 🧠 记忆闪卡（遗忘曲线复习）
- 📌 首页待办强制提醒
- 🗓 每周循环值日
- 🎨 6 套马卡龙皮肤
- 📚 38 篇教研文章

## 技术
- 单文件 HTML，全部 CSS/JS/图片内联（图片 base64 内嵌），零外部依赖
- 数据存浏览器 localStorage（键 `miffyWorkbench_v1`）
- 换电脑：设置 → 导出 JSON → 新电脑 → 设置 → 从本地恢复

## 开发
- 构建技能：`miffy-workbench-builder`（见 ~/.workbuddy/skills/）
- 历史版本：见素材包 `versions/` 目录
